Transactions analysis plan

Consider a transactions dataset with the following columns:

ColumnDescription
transaction_ida unique identifier for each transaction
customer_idan identifier for the customer associated with the transaction
store_idan identifier for the store where the transaction occurred
datethe date of the transaction
yearthe year of the transaction
totalthe total dollar amount of the transaction

Each row of the dataset represents one transaction.

Note: Customers can make more than one transaction at more than one store on a particular day.

Write an analysis plan for the question below.

  • Your analysis plan should start with the dataset above and result in a DataFrame that answers the question.
  • Your final DataFrame must only include rows that are relevant to the question. No extra rows.
  • Your final DataFrame may optionally include columns that are not required to answer the question. For example, if you are asked to identify customers, but your answer contains a transaction ID column that is not used, that's fine.
  • Your final DataFrame should require no additional computation to fully answer the question. A non-technical person should be able to answer the question by scrolling through your final DataFrame.

Make sure to use a subset of the appropriate canonical English terms learned in lecture.
