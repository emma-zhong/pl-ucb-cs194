# `pl-intent-console` element

## Attributes

| Attribute | Type | Default | Description |
| --- | --- | --- | --- |
| `answers-name` | string | required | Unique name used to store the student's input, generated code, and execution result. |
| `data-source` | string | required | Dataset available to generated code. The first version supports CSV files stored with the question. |
| `input-modes` | string |  required | `"english"` |
| `output-mode` | string | required | Language generated by the model. |
| `intent-spec` | string | required | YAML file describing the allowed data-transformation operations and their parameters. |
| `max-runs` | integer | unlimited | Maximum number of times the student may request new generated code for one question variant. |
| `row-limit` | integer | `20` | Maximum number of result rows displayed in the preview. |
| `timeout-seconds` | number | `3` | Maximum execution time for one run. |
| `generated-code-editable` | boolean | `false` | Whether the student may modify generated code before running it. |
| `weight` | integer | `1` | Weight used when PrairieLearn combines this element with other submission elements. |

## `output-mode`

`output-mode` fixes the generated language for the question. Students do not choose the output language inside the console.

### `output-mode="polars"`

- The model returns Python code using Polars.
- The question environment provides the `polars` package.
- The final DataFrame should be assigned to `result`.

### `output-mode="sql"`

- The model returns one read-only SQL query.
- The dataset is exposed as a table named after the file, without its extension. For `enrollments.csv`, the table name is `enrollments`.
- Data-modification and schema-modification statements are rejected.

## Intent specification

The instructor lists the transformations that the model may generate in `serverFilesQuestion/query_intents.yml`.

```yaml
intents:
  - name: group-count
    description: Group rows by one or more columns and count the rows.
    parameters:
      columns:
        type: column-list
        min-items: 1

  - name: sort
    description: Sort the result by one or more columns.
    parameters:
      columns:
        type: column-list
        min-items: 1
      direction:
        type: choice
        values: [ascending, descending]
```

The intent specification constrains the translator internally. The student does not see an intermediate “canonical interpretation.” The interface displays only the original English, generated code, and execution results.

## Translation contract

The translator receives:

- the student's English input;
- the dataset schema;
- the selected `output-mode`; and
- the operations allowed by `intent-spec`.

The translator may:

- convert the stated operations into valid code;
- select the syntax required by the configured output language; and
- resolve a clear reference to a column or operation.

The translator must not:

- add a filter, grouping, aggregation, or sort that the student did not request;
- change selected columns or sort direction to match the question prompt;
- compare the student's request with a reference answer; or
- use grading tests to improve the generated solution.

If the student's intent is ambiguous or uses an unsupported operation, translation fails with a neutral message asking the student to restate the query.

## Execution

Generated code runs in a restricted environment with:

- read-only access to the configured dataset;
- no network access;
- no access to other question or course files;
- an execution timeout; and
- a result-row limit.

The console keeps the generated code visible alongside the result so the student can decide whether the output matches the intended transformation.

## Submitted values

The element stores:

```text
school_counts-source
school_counts-input-mode
school_counts-output-mode
school_counts-generated-code
school_counts-result-schema
```

The `answers-name` value replaces `school_counts` when another name is configured.

## Grading

Translation and execution do not assign correctness. The question may grade:

- the student's English input;
- the generated code;
- the resulting DataFrame; or
- a combination selected by the instructor.

The translator never receives the grading criteria.

## Authoring errors

The element reports an authoring error when:

- `answers-name`, `data-source`, `output-mode`, or `intent-spec` is missing;
- `output-mode` is not `"polars"` or `"sql"`;
- the dataset or intent specification cannot be found;
- the intent specification references a column absent from the dataset schema; or
- a numeric limit is zero or negative.
